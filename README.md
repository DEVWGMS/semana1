Use o Codespaces do GitHub.
Se necessário, instale o VS Code no seu computador ou utilize um computador dos laboratórios da PUC Minas.
Com o VSCode, abra uma pasta, que configura um projeto dentro da ferramenta. Crie um novo arquivo de nome index.html (letras minúsculas) e monte uma página básica. Acesse a Internet, baixe uma imagem e coloque na pasta do projeto. Faça a referência da imagem no arquivo HTML. 
Salve o projeto, mantendo-o num repositório do GitHub.
Submeta o link do repositório do GitHub no Canvas.
